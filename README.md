# 아스트라이아 기동편 세계관 소개 시안

GitHub Pages용 정적 사이트입니다. `index.html`을 바로 열거나 로컬 정적 서버로 미리 볼 수 있습니다. 빌드 단계가 필요 없습니다.

## 임시 콘텐츠 교체

- **메인 이미지:** `index.html`의 `data-image-slot="hero"` 요소를 실제 이미지로 교체합니다. 이미지는 `assets/`에 둡니다.
- **인물 이미지:** `data-image-slot="person-01"`부터 `person-04`까지 각각 교체합니다.
- **인물 이름·소개:** `index.html`의 `people-grid` 안 네 카드에서 수정합니다. 현재 네 인물은 모두 UI 시안용 가설입니다.
- **AI 채팅 링크:** 채팅이 완성되면 `entry-card-bottom`의 준비 중 문구를 실제 링크로 바꿉니다.
- **공개 전:** 인물 가설을 실제 설정과 대조하고 `임시 설정`, `UI DRAFT`, 시안 안내 문구를 갱신합니다.

원본 설정집이나 제작자 전용 자료는 이 저장소에 넣지 않습니다. 세계관 문장은 드라이브의 《아스트라이아 기동편》 원전을 바탕으로 새로 요약했습니다.

## GitHub Pages

저장소 루트에 이 폴더의 파일을 올린 뒤 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**를 선택합니다. 프로젝트 저장소라면 기본 주소는 `https://<계정>.github.io/<저장소>/`입니다. 모든 내부 파일 링크는 상대 경로를 사용합니다.
