# 아스트라이아 기동편 · 세계관 기록 단말

GitHub Pages용 정적 사이트입니다. [공개 사이트](https://nanayad.github.io/astraea-site/)에서 볼 수 있으며 빌드 단계가 필요 없습니다.

## 화면 구성

- 메네사이트의 포획 성질·재료 가치·의료/합성체/조사/현상재현 용도를 탐색하는 첫 화면
- 메네사이트 시료 세 건의 기록을 확인하고 이송처를 고르는 `field-report.html` 체험. 모든 시료는 가상 시안이며 정식 사건 기록이 아닙니다.
- 체험 페이지는 메인 화면 첫 버튼, 고정 상단 메뉴의 `체험하기`, 메네사이트 구역의 진입 카드에서 열 수 있습니다.
- 세계의 핵심 개념과 칼덴·세레인·드라반의 대표 생활권
- 세 나라 홀로그램 지도. 기본 화면에는 세 국가명만 표시됩니다. 국가를 누르면 카메라가 그 나라로 내려가며 확대되고 도시명이 나타납니다. 도시를 누르면 더 가까이 다가가 측면으로 돌며 투명한 도시 골격과 설명을 보여줍니다. `전체 지도`로 처음 시점에 돌아갑니다. WebGL을 사용할 수 없는 환경에서는 드래그·확대·회전이 가능한 SVG 지도가 표시됩니다. 지형 윤곽과 굴곡은 도시의 기능에 맞춰 새로 디자인한 확정 지도안입니다. 원전에는 정확한 해안선·국경선이 없었으며, 현재 도시 좌표와 도시 골격은 배치 시안입니다.
- 작품 현재를 기준으로 한 상대연대 탐색
- 아스트라이아의 다섯 층군과 일반 귀환·응급·위험물 경로
- 네 명의 임시 인물 시안과 원전 직책에 맞춘 14인 기록부
- 공개 가능한 사실·관측·미해명 영역을 구분한 요약 기록
- 스크롤을 따라 고정되는 상단 메뉴와 현재 구역 표시

## 문안 편집

방문자에게 보이는 주요 문장은 영어 초안에서 일본어 문장으로 옮긴 뒤, 그 일본어 문장의 호흡과 번역투를 살려 한국어로 번역합니다. 마지막 한국어 단계에서 한국어식 홍보 문구로 다시 풀어 쓰지 않습니다. 최종 문구는 세계관 원전과 공개 범위를 대조합니다. 사이트에는 한국어 문구만 표시합니다.

## 임시 콘텐츠 교체

- **메인 이미지:** `index.html`의 `data-image-slot="hero"` 요소를 실제 이미지로 교체합니다. 이미지는 `assets/`에 둡니다.
- **메네사이트 이미지:** `ore-visual`과 `menesite.css`의 결정 도형은 원전의 공식 외형이 아닌 CSS 시안입니다. 정식 디자인이 나오면 이 영역을 교체합니다.
- **인물 이미지:** `data-image-slot="person-01"`부터 `person-04`, 그리고 `detail-portrait`를 교체합니다.
- **인물 이름·소개:** `index.html`의 `people-grid` 안 네 카드와 `script.js`의 `personnel` 배열에서 수정합니다. 현재 네 이름은 모두 UI 시안용 가설입니다.
- **AI 채팅 링크:** 채팅이 완성되면 `entry-card-bottom`의 준비 중 문구를 실제 링크로 바꿉니다.
- **정식 콘텐츠 반영 시:** 인물 가설을 실제 설정과 대조하고 `임시 설정`, `UI DRAFT`, 시안 안내 문구를 갱신합니다.

원본 설정집이나 제작자 전용 자료는 이 저장소에 넣지 않습니다. 세계관 문장은 드라이브의 《아스트라이아 기동편》 작업 원전을 바탕으로 새로 요약했습니다. 원전이 바뀌면 문안을 다시 대조해야 합니다.

## GitHub Pages

`main` 브랜치의 저장소 루트를 배포합니다. 모든 내부 파일 링크는 상대 경로를 사용합니다.

3D 지도는 저장소에 포함된 Three.js 0.187.0 모듈(`vendor/three/`)을 사용하므로 별도 설치나 빌드 단계가 없습니다. 라이선스는 `vendor/three/LICENSE`에 있습니다. 지도 구현은 `world-map-3d.js`, SVG 대체 지도와 팝업 조작은 `world-map.js`에 있습니다.
